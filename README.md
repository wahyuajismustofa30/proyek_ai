# proyek_ai

Repository kerja untuk proyek-proyek yang dikembangkan dengan bantuan AI.

## Mulai dari sini
1. Baca [AGENTS.md](AGENTS.md) sebelum mengubah file.
2. Baca [indeks proyek](docs/PROJECT_INDEX.md) untuk memilih konteks yang benar.
3. Baca instruksi proyek terkait sebelum membuat perubahan.
4. Kerjakan perubahan sekecil mungkin dan verifikasi hasilnya.

## Proyek aktif
- [DEKEKU — Brand System](projects/dekeku/README.md)

## Prinsip repository
- Dokumentasi dan instruksi menjadi sumber konteks AI.
- Arsip versi asli tidak ditimpa.
- Perubahan baru dibuat sebagai versi atau implementasi terpisah.
- Jangan mengarang data bisnis, harga, testimoni, kontak, atau klaim produk.
