# Archives

Folder ini menyimpan paket asli atau snapshot historis yang dipertahankan untuk audit dan pemulihan.

## Aturan
- Arsip bersifat immutable; jangan mengedit atau menimpa file.
- Perubahan dilakukan pada source kanonis di folder proyek, bukan pada arsip.
- Catat nama paket, versi yang ditetapkan, asal, dan catatan perbedaan metadata pada README proyek terkait.

## DEKEKU
- `Master-tema-dekeku-v1.1.zip`: paket asli yang ditetapkan sebagai baseline v1.1. Metadata internal paket memiliki beberapa label v1.5; lihat dokumentasi Brand System.
