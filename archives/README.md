# Archives

Direktori ini dipertahankan sebagai tempat arsip historis repository.

## Kondisi saat ini

Sesuai keputusan pemeliharaan repository, seluruh isi arsip telah dikosongkan. Hanya file `archives/README.md` ini yang dipertahankan agar direktori tetap tersedia dan tujuannya terdokumentasi.

Tidak ada paket, aset, skrip, atau subdirektori arsip yang saat ini disimpan di sini.

## Aturan pengelolaan

- Jangan menganggap file arsip lama masih tersedia di repository.
- Jika arsip baru ditambahkan di kemudian hari, dokumentasikan nama, versi, sumber, tujuan, dan status pemeliharaannya di sini.
- Jangan menambahkan kembali aset hanya untuk memenuhi pemeriksaan CI; aset aktif dan validatornya harus dikelola pada lokasi proyek yang sesuai.
