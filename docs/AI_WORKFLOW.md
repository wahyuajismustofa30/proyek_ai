# Alur Kerja AI

## Sebelum implementasi
- Identifikasi tujuan, target pengguna, platform, dan batasan tugas.
- Baca README proyek, instruksi lokal, dan catatan versi.
- Petakan file yang relevan; jangan membaca atau mengubah seluruh repository tanpa kebutuhan.
- Jika requirement ambigu dan berdampak besar, tanyakan satu klarifikasi.

## Saat implementasi
- Gunakan token, komponen, aset, dan pola yang sudah ada.
- Utamakan perubahan kecil, mudah ditinjau, dan dapat dibatalkan.
- Jangan mencampur aset sumber, file hasil build, dan output eksperimen.
- Simpan eksperimen di folder terpisah dan beri label jelas.

## Setelah implementasi
- Jalankan validasi yang tersedia.
- Periksa diff untuk mendeteksi perubahan tak sengaja.
- Perbarui README/CHANGELOG jika perilaku atau struktur berubah.
- Berikan ringkasan, hasil tes, dan keterbatasan.
