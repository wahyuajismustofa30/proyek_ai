# Alur Kerja AI

## 1. Sebelum implementasi

- Baca root README, root AGENTS, indeks proyek, README proyek, dan AGENTS lokal jika ada.
- Pastikan tujuan, pengguna, platform, ruang lingkup, dan batasan tugas.
- Periksa struktur, source, dependency, konfigurasi, serta pola yang sudah ada.
- Jika perubahan berisiko atau requirement penting belum jelas, ajukan satu pertanyaan klarifikasi.
- Nyatakan file yang diperkirakan terdampak sebelum perubahan besar.

## 2. Saat implementasi

- Kerjakan hanya pada folder proyek yang relevan.
- Gunakan source kanonis; jangan mengedit arsip atau baseline.
- Pilih perubahan kecil, terukur, dan mudah ditinjau.
- Hindari dependency baru tanpa alasan teknis.
- Jangan menaruh kredensial, data pribadi, atau file environment nyata ke Git.
- Pisahkan demo, eksperimen, build output, dan kode produksi.

## 3. Setelah implementasi

- Jalankan pemeriksaan yang sesuai dengan stack dan perubahan.
- Periksa diff, file yang berubah, tautan lokal, dan potensi secret.
- Perbarui README, CHANGELOG, indeks, atau catatan keputusan jika relevan.
- Jangan menyatakan test/build lulus jika belum benar-benar dijalankan.
- Laporkan ringkasan, daftar file, hasil verifikasi, risiko, dan pekerjaan tersisa.

## 4. Perubahan repository

- Perubahan struktur lintas proyek harus memperbarui PROJECT_INDEX.md.
- Perubahan aturan global harus memperbarui AGENTS.md atau STANDARDS.md.
- Keputusan arsitektur yang berdampak panjang dicatat di DECISIONS.md.
- Jangan menghapus arsip atau baseline tanpa instruksi eksplisit.
