# Pemberitahuan: Bootstrap Proyek Dihentikan

Fitur pembuatan proyek dari template telah dihapus. Direktori templates/ai-project/ dan script bootstrap tidak lagi tersedia.

Siapkan proyek melalui workflow pilihan Anda, kemudian unggah sebagai projects/<slug>/. Struktur internal proyek fleksibel dan tidak memerlukan scaffold tertentu.

Lihat [aturan struktur proyek](PROJECT_STRUCTURE.md) dan [indeks proyek](PROJECT_INDEX.md).

Dokumen ini dipertahankan sementara agar tautan dari panduan lama tidak menjadi tautan mati. Panduan lama yang masih menyebut template atau bootstrap tidak lagi berlaku; ikuti AGENTS.md dan docs/PROJECT_STRUCTURE.md sebagai acuan terkini.
