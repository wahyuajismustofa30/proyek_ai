# Foto

Taruh foto proyek di folder ini (portfolio, tim, hero).

- Format: WebP atau JPG, lebar maksimal 1600 px, di bawah 200 KB per berkas.
- Nama: huruf kecil dengan tanda hubung, misalnya `portfolio-toko-kopi.webp`.
- Selalu beri atribut `alt`, `width`, dan `height`, dan `loading="lazy"` di bawah lipatan layar.
