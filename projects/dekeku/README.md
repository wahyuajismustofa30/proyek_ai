# Proyek DEKEKU

DEKEKU menyediakan jasa pembuatan website dan undangan online.

## Area proyek
- [Brand System](brand-system/README.md): identitas visual, token, aset, dan pedoman tema.
- Pengembangan website dan undangan online dapat ditambahkan sebagai area terpisah saat mulai dikerjakan.

## Aturan konten
- Gunakan identitas visual DEKEKU yang telah disetujui.
- Jangan mengarang portofolio, harga, testimoni, kontak, atau klaim.
- Pisahkan kebutuhan website bisnis dan undangan online; keduanya dapat memakai fondasi brand yang sama tetapi memiliki UX berbeda.
