# Proyek DEKEKU

DEKEKU menyediakan jasa pembuatan website dan undangan online.

## Area proyek
- [Brand System](brand-system/README.md): identitas visual, token, aset, dan pedoman tema bersama.
- [Business Website](business-website/README.md): website bisnis, landing page, dan halaman layanan.
- [Online Invitation](online-invitation/README.md): produk undangan digital dan pengalaman tamu.

## Hubungan antararea
Brand System menjadi fondasi visual bersama. Business Website dan Online Invitation adalah produk terpisah: keduanya boleh menggunakan token dan aset brand yang sama, tetapi kebutuhan halaman, alur pengguna, fitur, dan model kontennya tidak boleh diasumsikan identik.

## Aturan konten
- Gunakan identitas visual DEKEKU yang telah disetujui.
- Jangan mengarang portofolio, harga, testimoni, kontak, atau klaim.
- Catat keputusan lintas produk di dokumentasi repository.
