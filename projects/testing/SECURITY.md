# Security Policy — Testing Web Page Lab

## Scope

Proyek ini adalah demo web statis tanpa backend, autentikasi, database, atau pengumpulan data.

## Reporting

Laporkan kerentanan melalui GitHub Security Advisories jika private reporting tersedia. Jangan mempublikasikan credential, data pribadi, atau detail eksploitasi pada issue publik.

## Safeguards

- Jangan menambahkan secret atau data pribadi.
- Jangan menambahkan script pihak ketiga tanpa review.
- Validasi input di browser hanya untuk pengalaman pengguna, bukan kontrol keamanan server.
- Jangan menghubungkan demo ke layanan produksi.
